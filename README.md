# Hospitality-data-analysis

## Project Overview

This project focuses on exploring and analyzing hotel booking data using Python and Pandas.

The analysis is performed using Jupyter Notebook to understand booking patterns, guest information, room categories, booking platforms, ratings, and booking status.

## Objectives

 Explore hospitality booking data.
 Understand booking patterns.
 Analyze guest and room information.
 Examine booking platforms.
  Analyze booking status.
 Identify useful insights from the dataset.

## Technologies Used

 Python
 Pandas
Jupyter Notebook
 CSV Dataset
